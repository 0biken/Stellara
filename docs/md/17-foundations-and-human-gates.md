# 17 · Foundations and human gates

## 1. Engineering deliverables

The monorepo uses Node 22, pnpm and Turborepo. Next.js 16 hosts the minimal web
shell; packages provide pure learning rules, client-safe and server-only Zod
schemas, theme tokens and English-first catalogues. Supabase directories reserve
future work only: no database or cloud resources are created by this foundation.

The pure rules package receives explicit state, identifiers, timestamps and
timezone. It returns immutable decisions and audit events. Server adapters must
validate identity, clock and pause evidence, deduplicate durable submissions, and
persist results transactionally. Passing library tests does not prove those
future database and API integrations work.

## 2. Approved v0.1.0 clarifications

The learning specification records the detailed thresholds. The approved choices
are: normal-confidence evidence only for Levels 3–5; strand-only placement with
ordinary scored-answer Stardust; proportional exam review compression; validated
pauses extending test deadlines; first-highest-transition milestone rewards; partial
awards at the daily cap; voluntary Rest Mode activity counting; a fresh retention
waiting period after returning to Level 4; and repair counting actual activity only.

Reports use consecutive Sunday 18:00 Lagos cutoffs. Late-Sunday activity belongs
to the next report; the report must show its actual period.

## 3. Academic review

The curriculum draft contains 74 topics across five **learning areas**, not five
official exam papers. It is an original planning draft awaiting academic approval.
Exam papers are modelled separately. The 2027 mapping, official item counts and
durations are not filled with guesses.

Reference: [NECO's 2026 general information](https://neco.gov.ng/2026%20NCEE%20ADVERT%20AND%20POSTER%20-%20GENERAL%20INFO.pdf)
describes two grouped papers. It does not confirm the 2027 format. Next.js 16 was
selected because [Next.js 15 security support ends on 31 January 2027](https://nextjs.org/support-policy), before the pilot finishes.

Academic review must confirm topic coverage, age suitability, prerequisite edges,
religious/moral education options, vocabulary, item allocation and exam mapping.
An unverified blueprint cannot pass the published-blueprint schema.
