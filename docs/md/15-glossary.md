# 15 · Glossary

| Term | Meaning |
|---|---|
| **Auntie Stella** | The tutor's name and voice for children. Appears in hints, notes and the parent report |
| **Blueprint** | Configuration describing a practice test: papers, item counts, duration, rules |
| **Class mode** | A teacher-started session on a school device where children sign in with a class code and picture PIN |
| **Constellation / sky** | The child's visual map of topics; each topic is a star whose shape shows its mastery level (a mastered star grows a sprout) |
| **Star sprout** | The Stellara logo: a honey star with a small face and two matcha leaves. Also the mastered state of a topic star |
| **Daytime** | The light theme: cream and honey |
| **Starlight** | The dark theme: warm cocoa with soft off-white text |
| **Match my phone** | The default appearance setting: Daytime or Starlight, following the device |
| **Picture key** | A child's sign-in: 4 pictures tapped in order ("PIN" in code only) |
| **Coverage** | Share of a paper's topics at `developing` or above. Never a predicted score |
| **Creche / KG** | Early-years settings (roughly ages 2–5); Phase 3 |
| **Days in a row** | Count of consecutive qualifying learning days |
| **DPA** | Data processing agreement (with schools and vendors) |
| **DPIA** | Data protection impact assessment, required before the pilot |
| **DPO** | Data Protection Officer |
| **ECCDE** | Early Childhood Care, Development and Education |
| **Edge Function** | Server-side function on Supabase (Deno) |
| **GAID** | General Application and Implementation Directive (NDPC, 2025) |
| **Item** | One question, version-pinned |
| **Learning day** | A calendar day ending at 03:00 local time |
| **Mastery level** | One of `not_assessed`, `foundation`, `developing`, `proficient`, `advanced`, `mastered` |
| **NCEE** | National Common Entrance Examination into Federal Unity Colleges, run by NECO |
| **NDPA** | Nigeria Data Protection Act 2023 |
| **NDPC** | Nigeria Data Protection Commission |
| **NECO** | National Examinations Council |
| **NERDC** | Nigerian Educational Research and Development Council (curriculum) |
| **Pack** | A downloadable set of practice items for offline use |
| **Placement check** | Optional strand-level check at the start; never called a test |
| **Practice test** | A timed, exam-style test with a server-owned timer |
| **PWA** | Progressive web app: a website that installs like an app and works offline |
| **Resting cloud** | An automatic protection that keeps the run going on a missed day |
| **Rest Mode** | Up to 14 days when the run is frozen (holidays, illness), set by an adult |
| **RLS** | Row Level Security in Postgres |
| **Scored response** | A response that counts as evidence of learning ([02 §2](02-learning-rules.md#2-scored-response)) |
| **Stardust** | Motivation points with a daily cap; never affects mastery |
| **Stimulus** | A shared passage or diagram used by several items |
| **Strand** | A group of related topics within a subject |
| **Topic** | The smallest curriculum unit with its own mastery level |
| **UBE** | Universal Basic Education |
